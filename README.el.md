# Μουσική τῶν Σφαιρῶν · Ἁρμονία τοῦ Ὄντος

**Δίγλωσσο, αυτόνομο ερευνητικό εργαστήριο ελληνικής μαθηματικής σκέψης με εξωτερική οργάνωση EFMW.**

**Ιστότοπος (μετά την ενεργοποίηση του GitHub Pages):** https://enuminous.github.io/Music-of-the-Spheres/

Ανοίξτε το [index.html](index.html) στον φυλλομετρητή. Επιλέξτε **Ελληνικά** ή **English**. Η εφαρμογή λειτουργεί χωρίς σύνδεση, εξυπηρετητή ή εξωτερικές βιβλιοθήκες.

## Επιστημολογικά όρια

Η ιστορική τεκμηρίωση, η σύγχρονη τυπική επαλήθευση και η υποθετική συνέχεια της αρχαίας σκέψης αποτελούν διαφορετικά επίπεδα. Η εφαρμογή **δεν αποδεικνύει** ότι το σύμπαν κυβερνάται από μουσικούς λόγους ή ότι η φυσική EFMW έχει επιβεβαιωθεί πειραματικά.

Στη **δοκιμαστική γηγενή μαθηματική γλώσσα** η ανυπαρξία δεν είναι κατάσταση, αντικείμενο ή μαθηματικό μέγεθος. Δεν εισάγουμε το μηδέν ως αριθμητικό στοιχείο. Αυτή είναι μια **επιλεγμένη υπόθεση** για το πείραμα, όχι δήλωση ότι όλοι οι Έλληνες μαθηματικοί σε όλες τις εποχές απέρριπταν κάθε σύμβολο κενής θέσης.

Η μονάδα διακρίνεται από το πλήθος, τα γεωμετρικά μεγέθη από τους αριθμούς, ενώ ο λόγος και η αναλογία εξετάζονται με κατασκευές και αποδείξεις.

## Περιεχόμενα

- **Κόσμος** — διαδραστική, εννοιολογική απεικόνιση των ουρανίων σχέσεων, όχι φυσική προσομοίωση.
- **Αρμονικός κανών** — διπλάσιος, ημιόλιος και επίτριτος λόγος, με προαιρετικό σύγχρονο ηχητικό παράδειγμα.
- **Εργαστήριο λόγου** — δημιουργία προτάσεων με τεκμήρια και σαφή βαθμό βεβαιότητας.
- **Παραδόσεις** — Ελεάτες, Πυθαγόρειοι, Πλάτων, Αριστοτέλης, γεωμέτρες, αρμονικοί, αστρονόμοι.
- **Πηγές** — πρωτογενή κείμενα, ιστοριογραφία, υποθετικές επεκτάσεις.
- **Lean 4** — εξωτερική μηχανική επαλήθευση περιορισμένων ιδιοτήτων του πειραματικού μοντέλου.

Για το πλήρες ερευνητικό πλαίσιο: [HARMONIC_COSMOS.md](HARMONIC_COSMOS.md), [HISTORICAL_ATLAS.md](HISTORICAL_ATLAS.md), [EFMW_PROTOCOL.md](EFMW_PROTOCOL.md).

## Επαλήθευση

Με Lean και Lake εγκατεστημένα:

```bash
lake build
# Προαιρετικός πρόσθετος έλεγχος σε Linux με λειτουργικό Bubblewrap:
# lake check
```

Οι αποδείξεις αφορούν **ορισμένες δομές**, όχι ολόκληρο το ιστορικό corpus ούτε ισχυρισμούς φυσικής. Η μοντέρνα μεταγλώσσα επαλήθευσης δεν ανήκει στη γηγενή ελληνική μαθηματική γλώσσα.

**Δημοσίευση:** ενεργοποιήστε *Settings → Pages → GitHub Actions* εάν δεν είναι ήδη ενεργό και ελέγξτε το αποτέλεσμα στις *Actions*.

**Σημείωση CI:** ο βασικός έλεγχος βασίζεται στην επιτυχή μεταγλώττιση Lean. Η πρόσθετη εντολή `lake check` απαιτεί ασφαλή sandbox με Bubblewrap και δεν εκτελείται στην προεπιλεγμένη μηχανή GitHub όταν απαγορεύονται τα σχετικά namespaces.
